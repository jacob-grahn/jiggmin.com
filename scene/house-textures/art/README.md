# House art prints

Three original, text-free graphic prints for the house props. Each has an editable SVG source and a matching opaque 640 × 640 RGB PNG for direct use as a Blender texture. The artwork uses a paper-cream field with ink navy, muted red, teal, orange, and a few subject-specific accents.

| Print | SVG source | Blender texture |
| --- | --- | --- |
| Fish in Blue Boots | `fish-boots.svg` | `fish-boots.png` |
| Tea Orbit | `orbit-teapot.svg` | `orbit-teapot.png` |
| Pear on a Ladder | `antenna-pear.svg` | `antenna-pear.png` |

`manifest.json` records dimensions, format, file sizes, hashes, palette, and a short visual description. The PNGs were rasterized from the SVG files with the bundled Sharp library; no extra package was installed.
