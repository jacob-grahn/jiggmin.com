# Keyboard surface

`keyboard-top.png` was generated with the built-in ImageGen tool for the workroom keyboard. It is mapped onto the top of a slim rectangular body; the keys have no individual geometry.

Prompt:

> Create a production-ready diffuse texture for the TOP SURFACE of a slim full-size desktop computer keyboard in a slightly worn home workshop. Perfect flat orthographic overhead view, keyboard rectangle fills the entire wide 3:1 image edge to edge, no surrounding background, no perspective, no visible side thickness, no cable, no logo. Dark charcoal gray keyboard deck, realistic low-profile off-white and gray keycaps with small conventional English QWERTY legends, full proper keyboard layout with function row, arrow keys and number pad, long space bar. Subtle texture and understated wear, neutral even lighting, only delicate key-edge shading, no dramatic shadows. This bitmap will be mapped directly onto a thin rectangular 3D keyboard; all keys are depicted in this single image.
