# Generated window exteriors

Created with the built-in image generation tool. The Blender room builder UV-maps these photographs into the windows; the final browser assets are baked into `web/assets/house/*.webp`.

## rainy-garden.png

Use case: photorealistic-natural. Asset type: exterior texture seen through windows in a midnight house 3D scene. Create a wide landscape photograph of a quiet rain-soaked garden at blue hour just after dusk: layered evergreen trees, leafy shrubs, an old low wooden fence, wet grass, distant mist and a luminous overcast slate-blue sky. Believable depth, softly moonlit leaves, restrained desaturated blue-green palette, no saturated electric blue. View at eye level from inside a house but DO NOT include any window frame, glass, interior, border, text, people, lamps or lights. Detailed natural photographic texture, atmospheric and tranquil, landscape 3:2 composition. Enough sky glow to plausibly illuminate a dark room.
